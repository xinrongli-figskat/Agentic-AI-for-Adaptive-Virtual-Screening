# Prediction-method scope

Prediction-method strength has been treated as an explicit experimental factor. The six-method set used for the current comparison is now fixed for this month; no additional proxy will be added to the current analysis. This keeps the work focused while preserving a comparison of methods with different complexity and data requirements.

The earlier statement that co-folding confidence is not an affinity estimate remains correct for confidence scores. It was incomplete as a description of Boltz, which also offers a dedicated affinity module. Protenix and Boltz are not included in this month’s experiments because the time and computational cost are substantial and a contamination review has not been completed. Their exclusion is a schedule and data-provenance decision, not a claim that they are scientifically unsuitable.
