# Research progress summary (22 October 2026)

This retrospective prototype uses a source-limited human tissue-nonspecific alkaline phosphatase (TNAP) evaluation set containing 462 compounds, of which 53 were measured as active under the project's fixed assay threshold. It is an evaluation of active-search control, not a blinded prospective screen. The statements below apply to the tested settings and are not claims about language-model controllers in general.

1. **The observed contribution is consistent with choosing a better overall selection-rule preference; we have not detected an additional benefit from timing individual rule changes.** For the prediction method with cross-validated ROC-AUC 0.821, the controller found an average of 11.325 active compounds among 50 selections. A static mixture using its own observed rule frequencies found 11.20; the paired difference was +0.125 (95% interval −0.650 to +0.975). In the original seven-rule setting, a coarsened comparison gave −0.10 (−2.25 to +1.80), but that comparison is descriptive because its rules cannot be made identical by grouping their names. When the controller could inspect the preset library, a new static mixture using **that controller's** observed rule-frequency weights found 12.85 actives, versus 14.25 for the controller: +1.40 (−0.40 to +3.25). In this finite sample the mixture actually executed 39 pure-ranking, 24 diversity-penalised and 17 random batches, compared with the controller's 54, 17 and 9, partly because one-class states invoke random fallback. Thus this control does not exactly match realised behaviour frequencies. All three intervals include zero; they do not establish exact equivalence or exclude a useful timing effect in a larger study.

2. **Access to the preset library improved the controller's rule choices in this setting.** With the same prediction method, five-rule menu, and seed-specific initial compounds, the controller that saw all candidate structures and current prediction scores found 14.25 actives in 50 selections, versus 11.325 for the controller restricted to numerical summaries: a paired gain of +2.925 (95% interval +0.424 to +5.550). An approximate sensitivity interval that also incorporates the measured between-run variation of the language model is +0.191 to +5.798. The proportion of batches using diversity-penalised ranking fell from 65.0% to 21.3%. The broader view plausibly corrected an unhelpful rule preference; the system instruction also changed to explain the visible library, so this comparison does not isolate the effect of structures alone. Unselected experimental results remained hidden.

3. **A fixed, retrospectively selected best rule still performed better.** Pure similarity-based ranking found 16.65 actives on average, exceeding the library-visible controller by 2.40 (paired 95% interval for controller minus fixed rule: −4.30 to −0.80). Against Thompson sampling under the tested five-rule setup, the controller's difference was +1.10 (−1.55 to +3.65), so a clear advantage was not established. The best fixed rule was identified after observing outcomes and is therefore an explanatory reference rather than a prospective rule-selection claim.

The library-visible comparison covers one evaluation set, one prediction method, one rule menu, and one model run per random seed. All analyses are post-exposure. Earlier experiments with different prediction methods or rule menus are informative context but not direct head-to-head controls. The present results do not determine whether the benefit of language-model control changes systematically with prediction accuracy. Repeated identical model requests can yield different rule choices, so the single-run comparison should be treated cautiously. A negative conclusion about added benefit beyond a strong fixed strategy remains scientifically acceptable.
