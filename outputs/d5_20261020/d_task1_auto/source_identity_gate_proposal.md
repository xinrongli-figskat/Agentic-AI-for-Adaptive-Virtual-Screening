# 下一版确定性来源身份凭证：提案，不回改 D5 运行

D5 的 TACE 模型判断将“12 个专利样本结构和立体化学尚未独立核对”视为可接受局限，输出 `review_shortlist`，而既有人工结论为 hold。这表明 `gates.py` 当前把来源状态交给 GLM 自述后，只能防止动作跳步，不能验证源分子身份。

建议下一版本在 `review_shortlist` 前增加可机器验证的 `source_identity_evidence` 字段：固定样本的专利例号、来源结构与 ChEMBL 标准化结构一一对应的核验表和哈希；若任何固定样本未解决、同一来源 ID 对应多个异构体、或原始值区间跨项目阈值，动作空间只允许 `hold`/`reject`。仍需独立人类审阅来确认化学结构的解读，机器只核验证据是否齐全及冲突是否已裁决。TNAP 的 PubChem SID/IC50 全记录对齐属于另一种来源证据，不应强行套用专利结构表模板。

这会改变未来版本的科学前提，须在新运行前单独锁规格和测试；不修改本轮 `agent_lock.json`、24 条 GLM 回执、TACE 的假阳性、任何旧的冻结物或 campaign。当前提案不构成已实现的新资格标准。
