# D5 Task 1 六项参照候选的受限自主审查

日期：2026-10-20 UTC。性质：**post-exposure 的参照集评估**，不是盲发现，也不是新的 benchmark 冻结。本轮以已固定的 R3 62 项数值通过排序表为输入，遵照用户修订，仅让 GLM 对 TNAP、ACC2、TACE、CPT2、ACLY、S1PR1 六项作判断；没有对第七项调用模型，没有重新画像靶点或进行新的 ChEMBL 请求。

共 24/30 次 GLM 调用，剩余 **6 次**。24/24 次得到合法并执行的动作；0 次格式失败，0 次前提拒绝，0 次候选范围外调用。供应商返回 prompt 16,062、completion 3,870、合计 19,932 tokens；24 次平均响应耗时约 3.84 秒。所有模型请求的原始响应、request ID、返回用量、耗时和动作存于 `llm_receipts/`。人工参照仅在六个模型判断完成后写入 `human_reference_postrun.json`，未进入任何模型提示词。

以 `review_shortlist` 作为阳性，**只对有明确最终人类参照的五项**计算：TP=1（TNAP）、FP=1（TACE）、TN=3、FN=0；precision=1/2=0.50，recall=1/1=1.00，五项中四项去留一致。阳性参照只有 **1 项**，这些比率不能外推，也不能当作候选发现性能。S1PR1 的人工状态只有“来源/端点未解决”的暂定记录，不混入正式 precision/recall 分母；其 GLM 暂缓与现有风险标记方向一致，但不等于匹配一份最终人工裁决。逐项可审计表见 `agreement.csv`，算式和分母见 `metrics.json`。

**关键失败模式是 TACE 假阳性。** 模型承认 12 个专利样本的结构和立体化学尚未独立与 ChEMBL SMILES 对齐，但将它归为“有限局限”，据此输出 `review_shortlist`。当前动作屏蔽仅保证顺序、格式、数值资格和模型自身 `source_status` 的一致性，无法替代独立结构身份核验。这是可检验的科学判断错误。系统并未把该草案变为可运行池：六个模型决定一律带 `campaign_ready=false`，没有冻结标签或启动 campaign。对未来版本可增加“结构身份核验凭证”这一确定性前提，但**不得事后改写本次锁定规则、TACE 回执或既有人工判断**；详见 `source_identity_gate_proposal.md`。

## 方法与门槛

输入是 R3 的 62 项数值通过排序（SHA-256 `dfb3569217454cd73a6c60b69128988aa1f57dc9866b7949728954933add47b9`）；本轮的六项在该表中分别位列 1、21、59、62、46、51。每项的 N、命中支持、**实测**非命中支持及结构门槛由固定 R3 行重新计算，均通过：N≥250、hit≥30、measured nonhit≥100、最大簇≤25%、骨架桶≥10、50 次查询占池≤20%、10 次初始化全为单类概率≤0.5。R3 的数值通过只解决计数/结构门槛，不自动解决来源与端点。

在模型调用前，六份**只含事实、不含人为去留结论**的证据包和代码/协议分别锁哈希：`input_lock.json` 记录原来源文件哈希与封存时间，`agent_lock.json` 记录实际执行代码、输入包及模型配置哈希。四阶段依次为 `inspect_metadata → read_evidence → assess_source → decide_assay`；前提不满足时 `gates.py` 屏蔽后续动作，单元测试涵盖跳步、非六候选、未通过数值门槛、来源 unresolved 时不得 shortlist，以及 shortlist 永不等于 campaign-ready。前两阶段的唯一允许动作已由程序限定，因此本轮的真正模型判断发生在后两阶段；不能将其宣传为 GLM 自主发现新靶点或独立选择检索路径。格式/请求错误原定每候选最多纠正一次，实际没有用到。

对来源为筛选数据库投递的 TNAP，在来源阶段使用已保存的测量深度检查：每行逐区间 IC50 拟合曲线数量 1–21、中位数 1，深度代理与标签关联 AUC 0.8785、点二列相关 0.4949。D5 在远端私有工作区重新从 462 个化合物级记录汇总得到 AUC `0.8785348526`、r `0.4948945406`，见 `tnap_depth_recheck.json`；**私有逐分子行未导出**。这个关联是测量工作量/选择偏差的解释性局限，既不进入公开 campaign 特征，也不是自动拒绝阈值。其余五项不具有已确认的 `deposited_screening_dataset` 来源层级，本轮没有可复算的逐分子深度证据；不能默认为深度均一。此项“投递筛选库应检查深度-标签关联”是本轮 Task 1 来源审查的新增检查，不能倒称为旧版本已预注册标准。

## Task 1 与 Task 2 的连接边界

本轮验证了“全库 SQL/结构整理产生排序 → 受限证据包 → GLM 对来源作草案判断 → 系统门槛和人工参照审计”的技术路径。TNAP 已有人为核实并冻结，GLM 此次与其有限资格判断一致；这**不意味着 TNAP 是本轮 GLM 自主构建的池**。`review_shortlist` 是待复核草案，**不等于 `campaign_ready`**。本轮仍未产生一个由 Task 1 智能体自主审查、独立批准并交给 Task 2 的新冻结池；因此 brief 所说的两任务自动闭环仍未完成。TACE 假阳性说明在自动转交前需要记录级结构身份的程序化证据，而不能只依赖模型文字判断。

这次六项均已在此前研究中暴露，R3 排名及事实包也来自 post-exposure 的人工整理。此评估检验的是在限定证据下的**来源判断与工具前提控制**，不检验全库发现率、未见候选泛化、或 GLM 相对其他模型的统计优势。旧 v1–v4 运行、DYRK3/TNAP 冻结物和旧 campaign 代码未改写；运行后选定哈希与 D5 基线一致。`STATUS=done` 仅表示这份受限评估完成，不表示科学资格问题已解决。
