## 检验结果与检验对象

四个有序分箱采用顺序分数 **0、1、2、3**。Cochran–Armitage 双侧线性趋势检验（对应 1 自由度卡方）检验策略比例随分箱的单调线性变化；另给出 2×4 Pearson 独立性检验（3 自由度），它检验任意分布变化，**不是**严格的线性趋势检验。bit 和 count 分开计算。

| 比较 | bit | count |
|---|---:|---:|
| greedy 线性趋势 | χ²₁=34.342, p=4.62×10⁻⁹，上升 | χ²₁=47.796, p=4.73×10⁻¹²，上升 |
| random 线性趋势 | χ²₁=17.937, p=2.28×10⁻⁵，下降 | χ²₁=22.493, p=2.11×10⁻⁶，下降 |
| greedy 2×4 Pearson 独立性 | χ²₃=38.388, p=2.34×10⁻⁸ | χ²₃=53.878, p=1.19×10⁻¹¹ |
| random 2×4 Pearson 独立性 | χ²₃=33.862, p=2.12×10⁻⁷ | χ²₃=36.663, p=5.42×10⁻⁸ |
| greedy：0 对 6+，Fisher 双侧 | 0/11 对 22/30，p=2.39×10⁻⁵ | 0/10 对 28/32，p=6.80×10⁻⁷ |

任务卡中 greedy 的 **2.3×10⁻⁸**（bit）和 **1.2×10⁻¹¹**（count）复现为 **2×4 Pearson 独立性检验**的 p 值。若称其为“趋势检验”，统计名称不准确；上表另给出真正针对有序趋势的结果。部分分箱中 random 的期望计数很小，Pearson 渐近 p 值只宜作为描述性检验，不能当作精确证据。

原 D4 报告中“上一批 0 对非 0 时，**diverse 对其他两项之和**”的 Fisher 双侧 p=**0.514**（bit）、**0.318**（count）已重算并核对，**对那个原假设本身没有算错**。其 2×2 表为 bit `[[5,6],[41,28]]`、count `[[3,7],[35,35]]`。问题在对比的选择：`其他`把零命中时常用的 random 与多命中时常用的 greedy 合并，掩盖了三项策略的转移；“这个对比不显著”不能推成“GLM 对反馈没有响应”。原报告中 3–5 对 6+ 的 diverse Fisher 结果也仍是该局部对比的结果，不受本补充修改。

**解释边界：**这些是同一个池中重复测量的决策（每个种子四轮）；轮与轮不独立，bit/count 也相关。上列常规卡方和 Fisher p 值没有对种子内相关、多重比较或观察后选取对比作校正，因此不可据此宣称预注册显著性或因果反馈规则。上一批命中数还受此前策略影响。可靠结论是轨迹显示：GLM 在低近期产出时避开 greedy，在高产出时偏向 greedy；它是否优于规定控制器，仍以 D4 的**配对 H@50 主比较**为准，而该比较没有支持额外收益。
