# D5 用户修订与执行边界

日期：2026-10-20。此文件记录用户在 D5 任务卡之后明确给出的修订；与任务卡冲突时，以这些修订为准。任务卡原件保存在同目录 `d5_task_card_source.md`，不改写旧的冻结协议或 D3/D4 结果。

1. Task 1 自主判断的 GLM 预算为 **最多 30 次**。评估调用仅限 TNAP、ACC2、TACE、CPT2、ACLY、S1PR1 六个已有人工参照结论的候选。未用完的调用也要报告。先做动作前提屏蔽，记录每候选调用数以及未能完成的理由。
2. 零样本方法只评估两个槽位：需要受体结构的打分方法，默认考察 Protenix-Dock 或经典对接打分；完全不依赖受体结构的配体侧方法。训练/结构污染和能否适用于两个池是优先否决条件。共折叠置信度不作为主候选，因为它衡量构象可信度，不能直接解释为亲和力。
3. **保留原 `knn_diverse` 定义**。如零命中机制核验支持，新增一个单独命名的策略供选择，不改写旧实现及其冻结快照。两个行为之间的差异应作为实验量来比较。
4. 第二波 GLM 仅在 TNAP 运行，最多 160 个决策；扩展的 CPU 控制臂在 TNAP 与 DYRK3 两个池运行。TNAP GLM 先运行 bit 的种子 0–9（40 个决策）作为检查点，核验后才运行剩余决策。DYRK3 用作无零命中初始化的阴性对照，不为它增加 GLM 调用。
5. 工作顺序中，D 的 Task 1/Task 2 连接优先，扩展菜单 E 随后。第一波各目录独立；主代理核验四份产物并写出 `d5_wave1_synthesis.md` 后，才能锁 E 规格、预检和运行。

以上是本轮任务授权范围，不使任何新候选自动取得 campaign-ready 资格，也不改变已冻结池的来源、阈值、标签或已完成 run。
