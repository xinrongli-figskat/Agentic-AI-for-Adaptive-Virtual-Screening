# D5 结果：扩展菜单、受限 Task 1 判断与两池 CPU 对照

日期：2026-10-20。性质：**post-exposure 回顾性实验**。它没有创建新 benchmark，没有重写 DYRK3/TNAP 的冻结池或 D3/D4 结果；所有数值均是固定池内、50 次查询预算下发现的实测命中数，而非直接结合证明。任务卡、用户修订、第一波汇总和运行前菜单规格保存在本目录。

## 对 brief 的直接结论

本轮将 Task 2 的菜单从“同一个 kNN 的三种采集规则”扩为七项，加入一个仅由已揭示标签训练的逻辑回归模型，以及一个有明确近似边界的 ENS 式单步前瞻规则。所有 CPU 与 GLM 臂共享这些工具、候选池、按种子的初始化和查询预算；原有 `knn_diverse` 没有改写。GLM 因而**确实有选择预测模型或分析规则的权限**，但在 TNAP 上尚无证据证明它优于一个简单、事后选出的固定单策略。它在 bit 主分析中优于一次预定的均匀菜单随机混合，不能由此推广到别的靶点或认定“智能体控制已胜出”。

Task 1 本轮采用 62 个数值通过候选的既有排序，限于六个有先前人工审查记录的候选做独立来源判断。它在 24/30 次 GLM 调用内做完六项，但将仍有专利结构身份疑点的 TACE 错列为待审短名单。所有草案 `campaign_ready=false`；**没有形成智能体独立产出并可自动转交 Task 2 的新冻结池**。因此两任务的数据接口仍可运行，科学审查到自动建池的闭环仍未完成。

## 两波工作的核验

第一波 A–D 的 73 个成员文件和四份 MANIFEST 已逐文件验哈希，目录未观察到交叉写入；详见 `wave1_verification.json` 和 `d5_wave1_synthesis.md`。A 的解析复核确认零命中时 kNN 贪心偏向远离已揭示非命中，却**不支持**“旧 diverse 必然比 greedy 更孤立”的批次排序推论。B 改正了 D4 统计对比的名称和解释，没有改写旧报告。C 审查了需要受体结构的 Protenix-Dock 和无需受体结构的 PSICHIC；因排序检查点/训练污染及构建体适用性未核实，两个方法均暂缓，未把 4090 GPU 的存在等同于已具备有效零样本分数。

D 的五项最终人工参照中，GLM 草案 TP=1、FP=1（TACE）、TN=3、FN=0，precision=0.50、recall=1.00；只有 **1 个阳性参照**，比率只能描述这五项。S1PR1 的人工结论仍是暂定来源/端点未解决，未计入分母。TNAP 的来源测量深度与标签高度相关（AUC 0.8785、r 0.4949），仍须作为测量工作量偏差解释，不能当作 campaign 特征。D 的完整证据在 `d_task1_auto/task1_auto_report.md`。

## E 的运行与对照

`d5_menu_spec.md` 在真实结果前锁定。两个池、两种表示、20 个种子下七个固定单策略与均匀随机混合共 **640** 组 CPU campaign；GLM 只在 TNAP 运行 bit/count 各 20 种子，共 **40** 组、**160** 个决策时点；按 GLM 实际策略比例事后生成的随机混合再跑 **80** 组 CPU。共 760 组，每组恰好 50 个不同化合物，共享同种子初始 10 个；既有 D3/D4 对照的初始 10 个也逐种子一致。首个检查点 bit 种子 0–9 共 40/40 次决策、无错误，之后才继续。所有 160 次 GLM 决策均有成功的 HTTP 回执，没有失败或自动承诺省掉的调用；返回的用量为 prompt 89,946、completion 9,510、合计 99,456 tokens，平均决策响应约 2.45 秒。这些是供应商返回的 tokens，**不是现金费用**。本轮 CPU 计算使用 4090 工作站的 CPU；尚未启用未经污染审计的 GPU 零样本模型。

H@50 是每个种子在 50 次查询中找到的实测命中数。下表为 20 种子的平均值；bit 为主，count 仅是敏感性分析。

TNAP bit 两项预定主比较的同种子配对 H@50 均值差：GLM − 最佳固定单项为 **−1.00**，描述性 bootstrap 95% 区间 **[−3.30, 1.65]**；GLM − 均匀菜单混合为 **+1.80 [0.15, 3.50]**。最佳固定单项在该数据上事后选出，三项同为均值 25.80，按锁定菜单顺序打平为“持续随机至首 hit”；这不是事前规定的获胜策略。count 敏感性结果分别为 **−1.60 [−2.20, −1.05]** 与 **+2.15 [0.60, 3.75]**。次要比较 TNAP bit 的 GLM 扩展 − D4 原 GLM 为 **+1.55 [−0.30, 3.95]**；扩展 − 既有强制冷启动规则为 **−1.00 [−3.30, 1.65]**。没有多重比较校正，20 个种子及同池事后设计不足以支持广义优势主张。

GLM 在 160 个开放时点选了旧 diverse 73 次、greedy 41 次、ENS 式代理 28 次、新冷启动 diverse 10 次、随机 5 次、逻辑回归 3 次、**持续随机承诺 0 次**。累计零命中时的 14 次选择只落在新冷启动 diverse（9）和随机（5）；有命中后它偏好旧 diverse。新菜单赋予了模型选择权，但模型很少选择第二预测模型，也一次都未选择此前表现良好的持续冷启动规则。TNAP 有 6/20 个种子在 10 次初始化后零命中；bit 下这些种子的 GLM H@50 均值 23.67、强制持续随机 24.33。GLM 的问题更像是**没有稳定利用最合适的菜单项**，而不能据此断言菜单扩大本身无用。

DYRK3 在两种表示下均为 **0/20** 个零命中初始化；固定 greedy 与新持续冷启动在全部 20 个种子中选择轨迹逐条相同，旧 diverse 与新冷启动 diverse 也逐条相同。这是对“新策略仅在冷启动时改变行为”的阴性控制。DYRK3 的固定逻辑回归平均值约 30.6–30.85，只是本池的探索性观察，不是 GLM 的收益，也没有在该池运行扩展 GLM。

## 方法边界、偏离与下一步

ENS 项是有 64+64 候选计算保护的**单步 0/1 幻想代理**，忽略批内 10 个候选的信息重叠，不是完整 ENS。匹配比例对照是在看到 GLM 选择后建立，且每个种子只实现一次伪随机菜单序列；它比 GLM 差不能单独证明 GLM 识别了因果最佳时机。事后最佳固定单项也偏乐观。TNAP 是来源受限的可行性池，测量深度与标签关联；DYRK3 小且命中率约 50%。本轮没有盲验证、没有第三个靶点，也没有将零样本模型接入共享菜单。

预检存在一处时间偏离：运行前的 28 组合成 campaign 与模型探测没有**明确执行已揭示合成标签置换的数值分数对照**。760 组运行完成后补做了仅用合成标签的只读检查：无标签随机选择不变、加权 kNN 分数随置换变化。原预检凭证未改写；这个补检不能追溯成“运行前已做”。D5 根本不使用 `structure_prior` 字段，故它的置换检查不适用于本版。详见 `DEVIATION_POSTRUN_BOUNDARY_CHECK.md`。冻结池、旧控制代码和 D5 规格的锁定哈希未变。

下一步先把 Task 1 的**结构身份核验凭证**变成 shortlist 的系统前提，之后在未见候选上重新评估，才考虑自动冻结与 Task 2 交接。若要论证 GLM 的额外价值，应在新的、来源已解决且命中不饱和的池上，预先固定更强的规定控制器及更多独立随机混合实现；不应依据本轮的单池区间修改已冻结策略。

机器可复核的每种子结果、配对差值、累计命中曲线、成本与阴性对照在 `e_menu_results.json`；私有逐次标签/选择轨迹只保留在远端 `outputs/d5_20261020/e_menu_private/` 和本机忽略 Git 的审计备份中。
