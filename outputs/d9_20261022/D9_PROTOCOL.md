# D9 locked protocol: library-visible controller

Date: 2026-10-22. Post-exposure experiment; not a new benchmark or blind validation. This file and the runner are hashed in `D9_LOCK.json` before any D9 provider call. Earlier D3–D8 records remain unchanged. This task does not use Git or the remote workstation.

The sole cell is TNAP × S_strong × bit, with the same frozen 462-compound pool, 20 seed-specific label-blind initial sets, 50-query limit and five-policy menu as C4. One repeat of seeds 0–19 makes at most 80 planned model decisions. Physical API calls are capped at 88, on top of the recorded project baseline 683 (cumulative cap 1,000). Model: glm-5.3-flash, no sampling, JSON object response, thinking enabled at low reasoning effort. Strict response keys are exactly `policy` and `reason`.

The controller additionally sees every preset compound key, standardized SMILES and current S_strong predicted probability. It sees only observed active/inactive keys after selection. It must not see an unqueried outcome, global hidden-label aggregate, threshold-near measurement, or measurement-effort variable. Four runtime assertions check this at every request, including comparison with the serialized request body; any failure stops the run. Each seed's initial ten keys must match C4. The policy descriptions and zero-hit commitment note are taken from C4 to minimize prompt differences; the D8 API system instruction necessarily describes the new visible-library setting. Thus the prompt wording is not byte-identical, a limitation for causal attribution.

At each feedback decision, an invalid format may be retried once with identical request bytes and a new physical call. The parser is unchanged. No fallback policy or retry beyond two attempts is allowed. Transport failures are saved and pause the run for inspected resumption. Physical attempts, request IDs, returned usage, elapsed time and raw responses are saved in the private D9 directory. A provider call is reserved in a receipt before network access. No API key is saved.

Seeds 0–9 form the mandatory checkpoint. Before seeds 10–19, check all completed runs, policy and realized-behavior counts, format-failure rate, and all four per-call boundary assertions. Any failed assertion ends the experiment. No additional repeat is authorized.

Primary analysis: within-seed difference in active compounds among 50 selections, D9 minus the mean of two C4 repetitions for the same seed. Report 10,000 paired seed bootstrap resamples with seed 20261018, and a second uncertainty interval incorporating the B-line model SD 2.1943108257491692 with one D9 and two C4 repeats, yielding model SE about 0.601. Secondary comparisons: D9 minus fixed greedy (16.65), Thompson sampling (13.15), and the D9 frequency-matched CPU mixture. Report policy-name and actual-behavior counts side by side, and actual prompt-token total and mean per decision. The C4 reference mean must reproduce 11.325; fixed S_strong greedy/diverse means must reproduce 16.65/9.65.

Prespecified interpretation: if the primary interval includes zero, visible library information has not shown a detectable improvement over C4 in this cell. If D9 is clearly better and approaches fixed greedy, the former information restriction plausibly mattered, subject to one cell, one pool, one repeat, post-exposure limitations. If D9 is worse, report that additional information did not improve performance. This experiment does not test whether gains vary with surrogate strength and is not directly comparable to D5's expanded-menu LLM or D7-A bandits.

Frequency-matched CPU comparator: use C4's trajectory-correct three behavior counts for S_strong; use D5 bit-only GLM seven-menu choices coarsened to three categories for S_incumbent. ENS and logistic greedy are coarsened as model-ranked/greedy-like, although their selections differ from the five-menu greedy action. This makes the latter comparator descriptive; it cannot isolate decision timing. SHA-256 deterministic draws use seed and decision round. Run every configuration twice and require identical full trajectories. Compare each to its same-seed LLM reference using 10,000 paired bootstrap resamples. Intervals including zero indicate no detectable timing effect; positive intervals excluding zero support timing information only when the policies and surrogate are otherwise comparable.
