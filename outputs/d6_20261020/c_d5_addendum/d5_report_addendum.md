## 1. 既有强制冷启动规则与 D5 的持续随机项是同一臂

TNAP 的 `forced_random_coldstart` 与
`fixed:persistent_random_until_first_hit` 在两种表示、全部 20 个种子的
`values_by_seed` 完全相同：bit 的均值均为 **25.80**，count 的均值均为 **24.95**。
因此，原报告中“GLM − 事后最佳固定项”的 **−1.00**，和“GLM − 既有强制冷启动规则”
的 **−1.00**，是同一组逐种子差值，并非两个彼此独立的对照。

这项重复计数也有一个有利的反面信息：D5 事后选出的最佳固定项，恰好等同于
D3/D4 已使用的强制冷启动规则。因此，把它称为完全由 D5 结果产生的“事后最优”
低估了该比较的设计连续性；它仍因在七项菜单中按本轮均值选出而带有事后成分。

TNAP 纯随机的实测均值为 **6.00**（bit 和 count 相同），与冻结池的解析随机期望

## 3. TNAP bit 的三方并列限制了解读精度

在 TNAP bit 上，`persistent_random_until_first_hit`、`logreg_greedy` 和
`ens_one_step_proxy` 的 H@50 均值都精确为 **25.80**。D5 按事前锁定的菜单顺序把
`persistent_random_until_first_hit` 作为并列“最佳固定项”，此规则正确。

更影响解读的是，三种选择机制在 20 个种子、50 次预算下得到同一均值。这说明 H@50
在该池和预算下接近可达上限，对有能力的策略之间的分辨率有限。后续功效设计应把这
作为约束：增加种子或采用更早的累计命中指标可以补充 H@50，但本结果不能区分这三个
强策略的相对优劣。

## 4. Bootstrap 抽样种子的记录

D5 的配对 bootstrap 使用抽样种子 **20261020**；项目此前惯用的种子为 **20261018**。
用旧种子对 D5 的 10 个公开配对比较逐一重算，均可复现同一结论，区间端点的最大绝对
变化为 **0.10** 个命中，属于重抽样抖动。它没有实质性影响，但应记录，避免未来合并
分析把两次 bootstrap 误当作同一抽样流。

以上均为记录层面的修订。D5 的结果仍是单池、post-exposure 结果；本附录没有创建
新的 campaign-ready 池，也没有改变 D5 对 GLM 额外收益尚无充分证据的结论方向。
