# Task 1 v2 资格规则审查

日期：2026-10-15。性质：看过此前探索结果后，为独立的新运行确定的操作性规则；不是盲态预注册，也不是 brief 的硬性阈值。精确配置见同目录 protocol.json。

## 为什么调整 500

Brief 要求解释可用化合物数、类别覆盖、多样性、冗余和查询可行性，没有指定 500 个化合物。v1 的 500 是我们的设计选择。仅因未达到它就放弃所有较小数据，不利于一个月内验证端到端流程；但为了让已有候选通过而临时改规则也会造成选择偏差。

本版本明确承认已经看过 DYRK3 的数据与策略结果，以及 Task 1 v1 的拒绝结果。新运行另存规则、代码和 prior_exposure.json。已有候选可以在新规则下重新审查，但不得称为独立发现或盲态验证，旧拒绝记录不回写。

| 层级 | 整理后的可用化合物 | 用途和理由 |
| --- | --- | --- |
| 优先审查候选 | ≥500 | 拟议 50 次查询占池 ≤10%，给顺序搜索留下较大的未查询空间。 |
| 有限可行性候选 | 250–499 | 拟议 50 次查询占池 ≤20%，可用于较小的流程演示；证据较窄，须单独报告。 |
| 当前方案不纳入 | <250，或任一其他必要条件失败 | 只表示不适合本次操作性方案，不等于没有科学价值。 |

250、500 和 20% 均不是普适统计学标准。更小的池也能做实验；本版本选择上述界限是为了限制资源与解释范围。DYRK3 的 231 个化合物继续按原技术原型协议解释，不因此删除或重定性为新层级数据。

## 两层共同保留的门槛

- 单一 assay、SINGLE PROTEIN 目录、IC50、ChEMBL B 类型、目标映射 confidence_score ≥9；完整获取该 assay 的 IC50 记录。confidence_score 是目标映射置信度，不是测量准确性分数，也不证明直接结合。
- 至少 30 个命中支持、100 个非命中支持的标准化化合物。阈值 IC50 ≤1000 nM 为命中支持；非命中只指该端点和阈值，不代表任何浓度下均无活性。
- 未知、来源 potential_duplicate、结构异常、同一身份跨阈值冲突、相互矛盾的删失界限及活动注释冲突，保留记录并按继承的数值整理规则隔离，不能补成阴性。
- Morgan 半径 2、2048 bit、包含手性的指纹；Butina 相似度阈值 0.7，最大簇占比 ≤25%；至少 10 个 Murcko 骨架桶，非环分子共用一个桶。它们是依赖表示的操作性检查，不是泛化证明。
- 提议查询总预算 50，初始化 10、后续每批 10，初始化计入总预算；50/池大小 ≤20%，均匀无放回初始化仅获得单一类别的概率 ≤0.5。具体新 campaign 的初始化、种子、策略、指标和敏感性分析还须在新冻结前确定。
- 至多抓取 2000 条 assay 记录；精确两两多样性计算上限 1500 个化合物。触及上限时不能把截断部分说成完整数据；须另做资源/协议版本审查。

来源判断优先于数值通过。程序不能从 “IC50 + B + confidence 9” 推断直接结合。合格数值整理最多导出 review_shortlist 草稿；原文样品身份、测量列、构建体/受体和实验解释尚须核实，然后才能另建冻结版本和受控 oracle。

## 已知来源限制及已见数据

1. DYRK3：已见 231 化合物、116/115 类别及全部 v1 策略结果；这是既有技术原型，不充当新版独立验证集。
2. Task 1 v1：已看过 60 个目标画像、4 个 assay 元数据、p300 与 P2X 的完整数值整理；原运行状态 finished、shortlist 为空。新运行逐项记录其目标、旧预算/类别和拒绝决定，并标明其为已见证据。
3. p300 CHEMBL5737918：数值支持 HAT 结构域 IC50；不同 Isomer 合并及全池样品到立体结构映射未解决。即使 368 个化合物达到新的数量层级，也不解除来源限制。
4. P2X CHEMBL5732233：来源支持 P2X2/3 异聚体功能拮抗，不能当作孤立 P2X2；跨专利身份仍有未解项。193 条重复标记的追溯不自动恢复标签，也不算独立重复测量。原 224 个可用化合物、72 个非命中也未达到新门槛。

以上两条 assay 限制写入 source_holds.json 并随代码哈希固定。GLM 只能引用和保留限制，不能删除。并非拒绝整个 p300 或 P2X 生物学目标；其他 assay 可以另行审查。异聚受体超出当前单蛋白目录范围，需要另定范围版本。

## 新搜索的选择偏差

先复用已见画像优先检查有数据的目标，再对其他目标按固定哈希顺序做便宜计数；只在实际计数的目标中排序。没有全数据库按化合物数排列的索引，不能声称已找到数据库中最大的 assay。目标窗口最多 2000 条，会漏掉后续记录；按需 list_assays 可补充查找，但仍受请求预算限制。

富集可测 IC50 数据、单 assay、阴性覆盖和多样性要求会改变入选分布。结果须报告检索覆盖、拒绝/保留理由、未知/排除比例和上限，不能将零候选解释为数据库没有合适数据。

## 信息与材料边界

新包不含 API 密钥；来源为公开 ChEMBL API，数值与结构整理继承 v1 工具并固定副本。数据库证据、LLM 回执和带标签草稿属于私有 curation 目录，不能让 campaign 进程访问。导出的 public/private 文件划分只是逻辑划分，不等于操作系统隔离；本包没有启动真实 campaign。后续规则变更、来源修正和标签恢复都必须另留版本记录。
