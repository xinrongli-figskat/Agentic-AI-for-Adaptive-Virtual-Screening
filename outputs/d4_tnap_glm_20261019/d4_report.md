# D4：TNAP v1 的 GLM 控制器与规定对照

**状态：完成，post-exposure 回顾性实验。** TNAP v1 使用单一实验定义的 1000 nM IC50 命中标签：462 个化合物、53 个实测命中。每个种子共用无标签的 10 次初始化，再做四批各 10 次查询。bit 为主表示，count 独立作敏感性检查；两者不合并。所有 40 次 GLM campaign（20 种子 × 2 表示）均完成，160/160 次策略决定、160 次 HTTP 尝试、0 次失败或重试，没有替换模型或暗中改用固定控制器。四个 v1 控制模块与冻结快照的 SHA-256 完全一致；合成探测成功，真实运行前预算和功效声明已锁定。完整逐化合物轨迹保存在私有目录。

H@50 是 50 次不重复查询中找到的**实测、实验定义命中**个数，不代表直接结合。主规定控制器在看到零个命中时按预先固定的规则随机探索，看到第一个命中后使用相同的 kNN 贪心工具。原 `fixed` 始终贪心，已知在 TNAP 冷启动时受到严重削弱，因此只列作次要对照。GLM 没有强制回退；它只能从 `knn_greedy`、`knn_diverse`、`uniform_random` 三项中选择下一批策略，实际化合物由同一 Python 数值工具选出。

## 主要比较

同种子 H@50 配对差值；每项 10,000 次配对 bootstrap，种子 20261018，括号内为 95% 百分位区间。区间不含 0 才描述为本池的观察差异；未做多重比较校正。

| GLM 减去对照 | bit 主表示 | count 敏感性 | 地位 |
|---|---:|---:|---|
| `forced_random_coldstart` | **−2.55 [−5.65, +0.55]** | −2.10 [−4.45, +0.90] | 主比较：两者均跨 0 |
| `structure_prior` | **+11.40 [+7.90, +14.25]** | +15.85 [+12.55, +18.70] | 主比较：两者均不跨 0 |
| `label_shuffle` | +19.40 [+15.40, +22.80] | +19.15 [+15.25, +22.60] | 次要反馈检查 |
| `fixed` | +2.90 [−1.15, +7.30] | +1.80 [−1.95, +5.80] | 次要；已知冷启动弱点 |
| `matched_proportion_tnap` | +3.95 [+0.55, +8.05] | +4.10 [+1.10, +7.45] | **事后**按 GLM 策略配比抽样的对照 |
| `random` | +17.25 [+13.80, +20.25] | +16.85 [+13.30, +19.95] | 仅附录式随机参考 |

GLM 平均 H@50 为 bit **23.25**、count **22.85**；规定冷启动对照分别为 25.80、24.95。GLM 明显利用了结果驱动的 kNN 工具，超过无标签结构排序和随机参考，但**相对规格更好的无 LLM 规定控制器，没有证据支持额外的智能体收益**。事后配比对照出现正差值，提示策略的时序可能重要；该臂比例取自同一批已见 GLM 行为，属于次要探索性分析，不能替代预先指定的主地板，也不能推断跨池优势。

## 六个零命中初始化种子

初始化的 10 次查询在种子 **5、6、15、17、18、19** 均无命中。这是共同初始化决定的前置分层，不是根据控制器结果挑选。第一个策略决定如下；括号内为 GLM 的 H@50：

| 种子 | bit 第一次策略 | count 第一次策略 |
|---:|---|---|
| 5 | random (24) | random (15) |
| 6 | diverse (25) | random (25) |
| 15 | diverse (15) | random (24) |
| 17 | random (25) | diverse (22) |
| 18 | random (25) | random (22) |
| 19 | random (0) | random (18) |

GLM 在首个零命中决策点选随机的比例为 bit **4/6**、count **5/6**。这说明它确实行使了 `fixed` 不具备的策略权；但单次选择随机并不保证之后找到命中。bit 的 seed 19 在 50 次查询后仍无命中。六种子平均 H@50：bit GLM **19.00**、`fixed` **6.17**、`forced_random_coldstart` **24.33**；count 分别为 **21.00**、**10.83**、**23.83**。GLM 减冷启动对照在这六种子上为 bit −5.33 [−11.67, −0.33]、count −2.83 [−5.83, −0.83]；其余 14 种子分别 −1.36 [−4.57, +2.43] 和 −1.79 [−4.93, +2.43]。小分层及多项未校正比较只应作机制诊断。

## 轨迹、反馈行为与成本

GLM 的 bit 平均累计命中（查询 10/20/30/40/50）为 **1.05/4.40/10.75/17.50/23.25**，count 为 **1.05/4.45/10.35/17.45/22.85**。10–50 的平均累计命中分别为 11.20 和 11.05；相对全池随机期望 50 × 53/462 = **5.736**，H@50 富集倍数分别为 4.05 和 3.98。这些指标表明搜索有效，不能单独证明 GLM 控制比规定控制器好。

bit 的 80 次决定中 diverse/greedy/random 为 **46/27/7**；count 为 **38/32/10**。按上一批新增命中 3–5 与 6+ 分组，选择 diverse 与其他策略的 Fisher 双侧检验为 bit p=0.0109、count p=0.000372；上一批 0 与非 0 的同类检验分别 p=0.514、p=0.318。以上是观察性关联，未作多重校正，不能视为 GLM 的因果反馈规则。完整分箱计数在私有分析文件中。

首次命中在 bit **19/20** 运行中观察到；seed 19 在第 50 次仍无命中，记右删失 **1/20**。bit 在找到命中者中的首次命中查询均值为 7.37，另列把未找到者编码为 51 的受限均值为 9.55；count 为 **20/20** 观察到、均值 7.80。51 只是受限汇总编码，不是观测到的首次命中位置。

模型返回用量：prompt **382,177**、completion **8,743** tokens，其中 reasoning **1,109** 已包含在 completion 中；160/160 决策均返回用量。模型决定总耗时 **296.15 s**，指纹构建 **1.21 s**，数值分析 **1.44 s**，化合物选择 **7.86 s**；数据采集时间属于冻结前阶段，D4 中未知，不补零。单次 HTTP 的状态和耗时、请求 ID 与 token 记录在私有轨迹中。合成探测另用 1 次 HTTP，433 prompt + 44 completion tokens，不计入 160 次 campaign 决定。跨版本累计使用量须另列，不能把 D4 返回 token 直接当作现金账单。

按既定 [800,1250] nM 区间，仅对已选择化合物作描述性分组：GLM 每 50 次查询平均选到的唯一精确近阈值分子 bit 2.45 个（其中命中 1.00）、count 2.50 个（命中 0.90）。不修改 1000 nM 阈值、不改标签、不重跑 campaign。D3 的来源层面近阈值身份为 13 个，严格唯一精确值为 12 个；其他删失/非唯一精确记录单列。

**解释边界：**TNAP 来源分类仍为 `limited`。蛋白构建体未明确；各化合物底层表征深度为 1–21 次拟合（中位数 1），与命中标签高度相关（AUC 0.879、r 0.495）。本结果是已见池的回顾性、实验定义命中检索，不是直接结合证明，也不能外推到统一测量条件的筛选或其他靶点。没有 decoy；所有主池非命中均为实测。分析过程发生一次 `arm_summaries`/`arm_stats` 读取键名的 **Tier A 机械故障**，保留失败现场、通过已知结果回归后在新 attempt 目录重跑；无 Tier B/C 改动。
