# D4：DYRK3 v1 与 TNAP v1 的跨池对照

两池都用相同的 50 次查询、10 次无标签初始化、四批反馈、bit 主表示、Morgan 指纹/kNN 数值工具与受限 GLM 三策略菜单。它们不是随机抽取的独立靶点样本，结论只限于这两个已见池。所有“命中”均为各自单 assay 以 1000 nM IC50 阈值得到的实测、实验定义抑制，不是直接结合证据。

| bit 表示下的量 | DYRK3 v1 可行性原型 | TNAP v1 来源受限池 |

同一套反馈驱动工具在两个池上回答了不同的问题。DYRK3 的 `fixed − label_shuffle` 区间包含 0；TNAP 上相应差值约 **16.5**，区间不含 0。这是**数据池对检验的区分力**不同，不是方法在两个靶点上有相反的普遍规律。TNAP 的错误标签臂甚至比无标签随机臂少 2.15 个命中；DYRK3 的同一错误标签臂略高于随机，这与其高命中率和化学系列集中有关，不能读成错误标签有益。

低命中率也暴露了冷启动设计问题：TNAP 的六个零命中初始化种子上，始终贪心仅得 6.17，预设随机回退得 24.33；DYRK3 的 20 个初始化都已有命中，故这一分支根本没有被实测考验。此前在 DYRK3 上的 `rule_adaptive_v1` 退化和 D3-0 取消冷启动回退的判断，都是通过保留可测量对照、在不同池上再检验，才发现其限制。这是资格标准与算法设计必须一同复盘的理由。

D4 的 GLM 在 TNAP 的零命中首轮多数选择了随机，具有实际决策权；整体上它超过无标签结构排序，却没有超过预先指定的、设计更完善的无 LLM 冷启动控制器。**在当前两池和同一预算下，没有证据证明 GLM 策略控制相对规格良好的规定控制器带来额外收益。** TNAP 的来源限制和不同化合物测量深度与标签强相关，尤其禁止把本结果推广为统一实验条件下的化学发现。DYRK3 是可行性原型，TNAP 是来源受限的第二个冻结池；它们都不支持跨靶点泛化结论。没有 decoy 结果，也没有把 decoy 与实测非命中混合。
