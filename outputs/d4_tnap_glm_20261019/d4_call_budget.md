# D4-1 call budget declaration

Pre-real-call, post-exposure TNAP v1 experiment. Seed IDs 0–19, two molecular representations (`bit`, `count`), four GLM decisions after the shared 10-query initialization: **20 × 2 × 4 = 160 successful policy decisions**. Each run uses exactly 50 oracle queries (10 initial + four batches of 10), without replacement. There were no previous TNAP GLM campaign decisions; all 160 are new. The one synthetic preflight probe is separately recorded and is not a campaign decision.

The frozen v1 `OfficialGLMDecisionClient` retries business code 1305 at most twice, waiting 5 and 15 seconds. Therefore a decision can involve at most three HTTP attempts; the absolute campaign ceiling is 480 attempts, plus one synthetic probe with the same retry ceiling. Other errors and 120-second read timeouts stop before the next oracle query. Successful policy decisions, HTTP attempts, failed attempts, returned tokens, request IDs, retry waits, and unknown provider usage are reported separately. No different model or controller is substituted. The cumulative project ledger must keep earlier DYRK3 and Task 1 GLM usage separate from this TNAP increment; prior records are not new D4 calls.
