## 目标

得到一张可解释的候选证据表，说明哪些蛋白的数据值得进一步整理、哪些需要补充证据或拒绝。此阶段属于数据发现与 ETL，不以 LLM 优于固定控制器为假设；控制器作用要在后续匹配评价中测试。

## 准备采用的工作顺序

### 1. 写出搜索范围与资格草案

第一来源拟用已连通的 ChEMBL。优先检查单一蛋白目标与可解释的 IC50 测量；B 类和较明确的目标映射可作为初版审查入口，但不能替代实验方法检查或直接结合证据。记录这一范围遗漏的功能类测量、其他 endpoint 和来源，以后根据证据缺口扩展。

每种测量独立统计，第一版不直接混合 IC50、Ki、Kd、EC50 和细胞毒性结果。同目标的不同物种、不同实验条件不能自动合并。

正式预筛前在资格配置中声明临时命中规则、计数门槛和预算假设。此前的每 campaign 100 次查询、其中 20 次初始化，只是计划起点，不是 brief 的固定数字。规则修改要写版本与理由；正式 campaign 开始前再审查并冻结。

### 2. 建立有边界、可复现的候选搜索

从明确的目标目录检索或抽样规则开始。第一批规模拟控制在约 30–50 个目标，数字属于工作量建议，不是合格标准。保存目录、查询条件、排序或抽样方法和覆盖范围，不把默认 activity 首页的 11 个目标作为正式候选全集，也不声称穷尽全库。

通过数据统计工具逐步获取 target、activity、assay 和来源信息。需要翻页、缓存和断点记录；API 总记录数与整理后可用化合物数分开列出。资格不足时扩大候选搜索范围或换来源，避免无限制下载与检查无关数据。

### 3. 先粗筛，再深入审查少量目标

粗筛考察目标身份、记录覆盖、结构和测量缺失、关系符号、assay 组成，以及暂定规则下潜在类别覆盖。不能凭记录数宣称合格。

对少量较有希望的目标，获取完整或有明确覆盖边界的数据，执行结构整理、单位处理、化合物去重、冲突与边界处理，查看 assay 兼容性，并计算结构多样性和类似物冗余。这一步才产生“可用”的化合物与类别计数。

| 资格维度 | 需要的证据 |
|---|---|
| 目标与 endpoint | 明确蛋白身份、物种、测量含义、实验方法和解释范围 |
| 数据量与类别 | 整理后化合物池足够支持预算；有实验命中和实验非命中，未知单独计数 |
| 实验兼容性 | 单 assay 或经过论证的可兼容合并；说明来源和条件差异 |
| 结构多样性 | 骨架或结构簇覆盖；类似物是否高度集中；整理规则造成什么偏差 |
| 搜索可行性 | 初始化是否可能只有一类；预算是否会迅速耗尽池；是否需要回退策略 |

阴性证据不足时，先根据缺口检查 PubChem 等来源或拒绝目标。只有明确标注构建方式和证据限制时，才考虑单独的 decoy 补充版本；未知活性不转换为实验非活性。

### 4. 形成短名单与理由

阶段产物是带 accepted-for-further-curation / needs-more-evidence / rejected 状态的候选表，以及资格草案、来源快照和决策记录。对完成深入审查的目标另列实际资格结果；粗筛排名不能冒充正式资格通过。

初版倾向完整实现一个合格目标，时间允许再扩展到第二个。任何目标数量都是方案选择。排名依据数据条件，不依据疾病重要性、目标知名度或后续 agent 的表现。

## 如何接入第一个智能体

将检索、assay 审查、结构统计和资格评估作为结构化工具。先验证工具输入输出；随后尽早接 GLM，让它根据证据选择下一步：追加实验说明、检查冲突、换来源、扩大候选范围或拒绝目标。记录可见证据、选取的动作和简要依据。

规则全部固定、LLM 只写总结的流程不能算完成数据构建智能体。控制器接入、GLM 型号和运行预算尚待落实；本阶段方案不代表它们已经实现。

## 与 brief 的对应及后续连接

| 原始要求 | 本阶段贡献 | 仍需完成 |
|---|---|---|
| 识别候选蛋白目标 | 声明范围并建立候选搜索和证据表 | 第一个智能体实际管理检索与审查 |
| 建立 qualification criteria | 草案和整理后计数、多样性、兼容性与预算审查 | 正式评价前审查与冻结 |
| 排序并选择 shortlist | 数据条件驱动的排序和拒绝理由 | 正式 benchmark 的完整整理与版本包 |
| 结构、测量、重复、冲突、边界与来源 | 工具与少量目标的深入审查 | 对选定 benchmark 完整执行并核验 |
| 固定池上的反馈搜索 | 提供后续化合物池和存储结果基础 | 受控查询、数值选择、第二个智能体和匹配评价 |

确定合格数据后，下一条连接任务是构建固定化合物池和隔离的结果接口，让简单固定策略先跑通有预算的查询循环，再接入主动搜索智能体。初始化计入查询预算，计算和 LLM 成本单独记录。
