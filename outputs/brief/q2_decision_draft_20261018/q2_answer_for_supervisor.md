post-exposure 的证据整理，不是新 benchmark、盲验证或新 campaign。

# 导师 Q2：实测非命中覆盖与 decoy

是的，已遇到非命中覆盖不足的候选。在 ChEMBL 37 的 512 个达到元数据预筛的 assay 中，有 226 个同时满足来源 ID 层面的总支持数 ≥250 和命中支持 ID ≥30，但实测非命中支持 ID <100；其中 48/226 个已有 50–99 个非命中支持 ID。这个数字是**预筛分支**，不能把来源 ID 等同于整理后的独立化合物，也不能推论整个数据库中只有这些候选。

对 226/226 个 assay 复用原结构与数值整理流程后，66/226 个只有实测非命中门槛不满足（A）；94/226 个还存在规模、查询占比或初始化风险不足（B）；66/226 个有其他门槛失败（C）。在“接近非命中门槛”的 48 个里，A=40/48、B=0/48、C=8/48。这说明非命中覆盖确实是一个实质的**数值障碍**，尤其是 A 类，但没有一个因此自动成为科学上合格的数据集；来源、端点和化合物身份还未批准。

我考虑了三条路。首选仍是已有**实测**非命中：先核对同一靶点且方法兼容的其他 assay；合并前需分别核实构建体、物种、IC50 测量方法与重叠化合物的一致性，并新建版本。对无法得到实测负例的候选，默认不纳入主 benchmark。性质匹配的 assumed-inactive decoy 只能另建、单列为敏感性分析，用不同标签类型保存，不能计作 measured nonhit，也不能替代现行 ≥100 实测非命中门槛。其可能带来选择偏差、未知假阴性，评估的将是区分已知活性与假定非活性，而非真实筛选的命中恢复。

作为规模估算，若纯粹**假设**往 A/B 类每池加入足够多的“负例计数”以满足数量、占比与初始化约束，160/160 项在不超过 2,000 的搜索范围内有数学解；所需额外数的中位数为 83（四分位数 50、97.5）。对应额外数与现有命中数之比在这 160 项中为约 0.01–0.40，中位约 0.19。**这些不是推荐的 decoy:hit 比例**，也没有生成任何 decoy；由于 decoy 不算实测非命中，单靠它们仍不能让这些池通过当前资格门槛。

当前科学结论限定为：确有 66 个数值上“仅差非命中”的 assay；它们的来源与实验含义仍需核查。尚无证据说明 decoy 增强能消除这个问题，故不把 decoy 池作为本月主结果。
