# C3 five-policy meta-controller correction (post-exposure)

Date: 2026-10-21. This is an additive correction to the completed 1,880-run C3 matrix. The old code, receipts, trajectories, and conclusions remain archived unchanged. It does not create a new benchmark or alter frozen pools, labels, surrogate fits, query budget, initialization, or fixed-policy trajectories.

All six surrogates on TNAP and DYRK3 use exactly the following five named actions, in this order: `greedy`, `diverse`, `random`, `persistent_random_until_first_hit`, `diverse_random_coldstart`. `ens_one_step_proxy` is absent for every surrogate. Three meta-controllers (`bandit_thompson`, `bandit_ucb1`, `random_mixture`) run each cell on seeds 0–19, for 6 × 2 × 3 × 20 = 720 CPU campaigns. Each run queries 50 distinct compounds, with 10 label-blind initialization queries and four batches of 10. Initialization and oracle remain as in C3 v3. No GLM calls.

The controller reward remains newly discovered hits divided by the previous batch's 10 queries. Thompson uses Beta(1,1) priors; UCB1 uses the existing infinity-first rule. Random mixture draws uniformly among the five named actions. Versioned SHA-256 seed namespaces avoid conflating five- and six-menu trajectories. The persistent action keeps selecting random until the first hit. No hidden label, assay metadata, or oracle private state enters a controller decision.

The original four common fixed arms and random floor are retained after hash verification. Their prior H@50, `spread_nontrivial_common`, and bootstrap intervals remain the fixed comparisons. This correction replaces all six-menu meta H@50 values in comparative analysis, including the four non-GBDT cells, so all six proxies face the same choice set. `adaptive_gap` is the best common fixed mean minus the best of the three new meta means. The six-point AUC versus gap Spearman rank correlation is descriptive, post-exposure, and noncausal.

The one-class fallback remains random as authorized. Under this implementation `greedy` and `persistent_random_until_first_hit` can coincide, and `diverse` and `diverse_random_coldstart` can coincide. Five *named* actions can therefore represent only three distinct behaviors in one-class states. The random mixture weights named actions equally, effectively 40% greedy-like, 40% diverse-like, and 20% random-like when the paired actions coincide. This is a limitation of the menu, not an unrecorded adjustment.
