## A3 的预期没有得到支持

原卡的条件解释是“若余量随决策点增加而显著上升，说明现行 4 点设计本身压制了任何自适应控制器”。在这次测量中，前提没有出现。TNAP 的固定六臂均值极差从 g2 的 9.25，降至 g4 的 7.35，再降至 g8 的 5.70。g8−g4 的逐种子极差均值变化为 TNAP −0.30 [−1.85, +1.30]、DYRK3 −0.65 [−1.65, +0.50]，均未显示增加。

因此，作为对本项目空结果的具体解释，“4 点限制压低固定臂跨度”没有得到支持，撤回该解释。不能由这个有限设计推出“决策次数永远不影响任何自适应控制器”的普遍因果结论。任务卡要求的“被证伪”在此限定为该项可观察预期未实现，而不是证明所有潜在机制均不成立。

## 固定臂跨度与自适应差距是两个量

`spread_nontrivial` 是六个非随机固定臂的均值极差，衡量本菜单中固定策略表现是否不同。它不等于自适应控制器的收益。TNAP Thompson 的 H@50 随 g2/g4/g8 为 18.25/20.55/22.75，即使固定臂跨度下降，bandit 仍可能改善。原卡将二者混同的解释不再采用。

新增 `adaptive_gap = max(固定六臂均值) − max(自适应臂均值)`，bandit 家族和 GLM 家族分别计算。下表使用既有 D5 工具菜单；没有新代理模型格子。每次配对 bootstrap 都重新选两侧最大值，10,000 次，种子 20261018。完整结果与所有固定臂对每个自适应臂的差值存于 `s2_s3_addendum/adaptive_gap_descriptive.json`。

## S3 粗估区间：算术可复现，收益解释仍停止

任务卡给出的四个区间可以用 `均值 ± 1.96√(20种子配对差值样本方差/20 + 4.20²/20)` 精确复现至两位小数：

| TNAP | GLM−bandit 样本均值 | 任务卡给出的粗估区间（非正式方差校正证据） |
|---|---:|---:|
| bit Thompson | 4.25 | [0.52, 7.98] |
| bit UCB1 | 7.80 | [3.24, 12.36] |
| count Thompson | 2.95 | [−0.26, 6.16] |
| count UCB1 | 6.00 | [2.03, 9.97] |

但 **4.20 的定义错误**：D6 保存的十个 D6−D5 差值为 0, −3, 0, 4, −1, 0, 2, 11, 0, −4；4.20185 是这些配对差值的样本 SD，不是“每种子单次模型 SD”。在独立同方差这一额外假设下，差值 SD/√2 为 2.97116；两次重复的池化组内 SD 为 2.88964。这两个探索性换算也不替代 D7-B 正式测量。把 bit 噪声用于 count 还需要未验证的外推假设。20 种子配对差值本身已含一次模型实现，直接再加噪声方差可能重复计入。

所以表格必须标为 **任务卡给出的粗估，因 SD 定义错误不能作为收益证据**。四区间的算术复现不等于统计有效性验证。按 Tier B 暂停“首个经方差校正后正向收益”的主张；见 `s2_s3_addendum/BLOCKED_variance_definition.md`。该问题不阻塞 S2，也不阻塞按预锁设计执行 D7-B 的正式模型方差测量。

仍应记录两个限制：UCB1 在 g4 只够按菜单顺序尝试前四个未试臂，属于较弱的短预算参照；固定最佳在 TNAP bit 均值 25.80，GLM 为 24.80，样本内仍高 1.00，但不能仅凭事后最佳断言所有场景均更优。count 的 GLM−Thompson 粗估区间含 0；不将其包装成跨表示一致收益。
