## 已实现

针对完整获取的 CHEMBL4575 / IC50，选择 CHEMBL5363961。校验发现阶段代码快照与响应哈希、分页覆盖、activity ID、数据库版本，以及重新计算的初版 assay 支持计数。

执行结构解析、单含碳片段保留、Cleanup、保留指定立体信息与同位素的规范表示；记录原始表示、被移除片段、规范化变化、结构失败、同 ID 多结构、不同 ID 合并。去电荷只作敏感性分组；不自动合并互变异构体。

复用初版数值资格逻辑，保留原值、单位、关系和来源。对于跨命中阈值冲突、删失范围不相容或命中与 inactive/inconclusive 注释不一致的化合物，标为待审查并不计入暂定可用池。精确测量报告范围而不自动求均值；未知不成为非命中；不生成 decoy。

计算原型可用池的骨架、Morgan 相似度和 Butina 聚类；报告近邻和类似物集中情况。对 50 次查询/10 次初始化以及 100 次查询/20 次初始化作数量可行性分析，初始化计入总数；报告随机期望、抽中单一类别的概率、剩余查询与反馈批数。

## 实现检查

本机独立检查依赖位于项目 .cache/audit-deps，不修改系统 Python。使用 Python 3.12.14、RDKit 2026.09.1、NumPy 2.2.6。九项离线检查覆盖：删失边界与矛盾；未知与来源注释；浓度单位和不求平均；盐/立体/同位素/混合物；结构合并后的标签冲突；多样性空池与小池；预算计入初始化；合成完整流水线和输出哈希；截断/被改动来源拒绝。

检查中的数据明确标为合成测试数据，不代表实际 DYRK3 结果。首次检查的两个文件场景遇到 Windows sandbox 临时目录写入限制，改为项目内已确认路径后九项通过；没有改变科学判断规则来使检查通过。
