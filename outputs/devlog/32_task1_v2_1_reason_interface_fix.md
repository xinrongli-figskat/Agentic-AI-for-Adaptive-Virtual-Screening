## 修复及保留边界

新增独立包 curation_agent_v2_1。唯一理由位于 `$.reason`，模型参数中禁止 `reason`；程序将外层理由传入来源评估、去留决定或结束记录。给出完整布局示例与明确 JSON 路径反馈。

仍严格校验工具、证据、必要参数及数值门槛，仍最多自动纠正两次。没有自动接受旧的错误回复，也没有跳过任何科学检查。资格规则、来源限制、模型和总预算保持原值。

continue-v2 将当前已暂停运行复制为独立的软件版本延续。旧证据、旧回执、已有拒绝、请求数和返回 tokens 保留，19/40 已用意味着只剩 21 次请求。旧状态与代码快照另存，新旧版本关系有哈希清单。不会把延续描述为独立或盲态新实验。重复准备不会重置已经前进的新目录。

旧 v2 代码和父运行不覆盖；父运行只取得既有写锁。数据清单排除该操作系统锁文件，全部科学证据和回执纳入哈希。版本延续后只运行新目录，保留原格式失败作为软件失败案例。
