# 候选摸底工具实现记录

日期：2026-10-14。用户要求推进下一阶段，已准备 `candidate_discovery_v0` 工具、资格草案和离线检查。本文记录实际实现范围；尚未形成正式 shortlist 或完整智能体。

## 初版实际实现

- ChEMBL 单一蛋白目录分页，固定 seed 的哈希顺序选取候选。
- 按候选目标检索 IC50，限定窗口并显式标记完整性。
- B 类记录的暂定阈值支持统计；处理浓度单位和不等号，保留未知与审查原因。
- 分 assay 统计化合物 ID，区分同 assay 内的阈值分歧与跨 assay 的两类支持。
- 来源字节、URL、版本、时间、SHA-256、请求限额、响应期限和完成标记。
- 生成用于后续审查的候选 CSV、详细 profile、实际配置和运行代码快照。

暂定命中统计阈值为 1 µM；初步审查优先级门槛为单 assay 500 个支持 ID、30 个命中支持、100 个非命中支持。这些都是可修订的工程选择，不是原始 brief 的指定标准，也不是整理完成的化合物数。

## 离线验证

九项检查通过，包括边界等号与严格不等号、单位转换、缺失或异常值、同 assay 分歧、跨 assay 不拼接、完整与截断分页、重复分页和总量变化拒绝、候选选择可复现、原始字节和哈希保存、失败状态保存，以及期限到达后保留部分响应并写日志检查点。

## 第一次真实工程试验及改动

v0.1.0 首次真实请求返回单一蛋白总量 11055，第一页 1000 个目标的完整响应约 6.5 MB，传输较慢。该次运行由我们主动停止，没有得到完整目录或候选表，不能算成功摸底。代码快照和已收到的响应保留在本机 `candidate_discovery_runs/discovery_20261014T113602Z_8e21c59c/`；停止时未生成最终运行元数据，此审计缺口不作虚构补写。

v0.1.1 使用官方 `only` 参数投影目录所需的四个字段，沿用原搜索范围和选取规则，并增加分块读取期限、请求检查点与代码快照。完成对应修改后，九项离线检查通过。

## 下一阶段边界

初步类别支持不等于已验证的 compound-level 标签。未完成 RDKit 结构处理、多样性、assay 方法与映射、来源和测量冲突审查；所有结果都保持 benchmark_qualified=false。当前 LLM 调用和 oracle 查询均为零。

正式批次应在远程运行，以保存至数据盘。原型应根据这些结果进一步取回有用目标的 assay 或改变检索范围；控制器接入 GLM 后才能完成第一个 agent 的证据驱动动作。

## 真实小规模验证已完成

v0.1.1 已完成真实运行，数据库 ChEMBL_37；完整目录含 11055 个单一蛋白目标。按同一 seed 选择前三个目标，每个最多读取 200 条 IC50 记录。共 16 个 HTTP 请求，HTTP 耗时合计约 127.33 秒，接收约 2.09 MB（十进制）。没有调用 GLM，没有 oracle 查询。结果目录为本机 `candidate_discovery_runs/discovery_20261014T114105Z_0c3616b8/`。

|---|---|---|---|
| CHEMBL4822，Beta-secretase 1，人源 | 13777 | 200，涉及 192 个化合物 ID | 窗口不完整，需要完整或按 assay 获取；不能外推全目标类别比例 |
| CHEMBL5021，Cyclin-dependent kinase inhibitor 1，人源 | 60 | 60，涉及 32 个化合物 ID | 暂定 B 类范围中无非命中支持，需补证据或审查范围；并非断言所有来源都无非命中 |

第一项目标在 200 条窗口中有 83 个命中支持 ID 和 87 个非命中支持 ID；这是来源未完整、结构与 assay 未审查的证据集合，不能当作正式 benchmark 类别。第二项目标的 56 条记录属于初版 assay 范围外，保留为待审查信息，不转成实验非命中。

声明的候选窗口任务 completed=true，三个 profile 均 benchmark_qualified=false。真实运行验证了官方字段投影、目录分页、记录上限、固定选取方法以及三种不同后续审查状态。正式 30 目标批次尚未在远程运行。
