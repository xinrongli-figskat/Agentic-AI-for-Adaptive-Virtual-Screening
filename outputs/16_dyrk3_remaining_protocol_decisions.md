# DYRK3 运行前补充决定（尚未冻结）

记录日期：2026-10-14。本文件在任何真实 DYRK3 campaign 之前制定；研究者已在整理阶段见过部分类别和边缘 IC50 值，所以不是独立盲法设计。该池仍是单 assay、同系列化合物的可行性原型。

## 已确定的技术规则

- 保留 231 个已导出的候选与私有标签；公开候选 SHA-256 为 `0e1d745fe49c9d5f1aeed732f54388ece05b56f5670c424db92e4c7711943800`，私有标签 SHA-256 为 `eaa0c992023e51740c81f14a42960d382e6f5c9e1dfa8d1f587fdff5fa03a0b6`。正式冻结时须在远程机上重新核验原文件，且记录完整工具源码哈希。
- 主表示为 RDKit Morgan radius 2、2048-bit、含手性的位指纹；kNN 用 5 个最近已揭示分子、Tanimoto 相似度平方加权、先验权重 2。贪心策略取预测命中分数最高的分子；多样性策略在同一分数上减去 `0.2 ×` 与已查询及本批已选分子的最大 Tanimoto 相似度。相同评分用原草案的带 seed SHA-256 规则打破并列。
- 计数指纹为预定的次要表示检查，使用相同 Morgan radius 2、手性及稀疏计数、同样的 kNN 和查询预算。不能根据主结果选择哪个表示当主结果。真实池中三组位指纹相同但标签混合的结构给出这一检查的动机；这并不修订标签。
- 固定控制器四轮都选择 `knn_greedy`。LLM 控制器每轮仅根据已揭示结果的摘要，从 `knn_greedy`、`knn_diverse`、`uniform_random` 三种数值选择工具中选一个并给出理由。数值计算和 ID 选择由 Python 完成；模型不获得私有文件、任意 shell、公共 bioactivity 查询或 oracle 对象。模型决定无效时停止在查询前并记错误，不默默换为固定策略。
- 推荐先测试智谱官方 `glm-4.7-flash` 的连接。当前连接测试尚未执行；若该模型不可用，须在真实标签查询前选择并记录替代模型。记录每次模型请求的模型名、响应 ID、token 用量和耗时，不记录 API key。

## 阈值附近的预定诊断

- 主标签和 1000 nM 阈值保持不变。对**等值、精确** IC50，定义闭区间 `[800, 1250] nM` 为阈值附近。这个范围是距 1000 nM 上下各 1.25 倍的对数对称区间，仅用于粗略稳健性诊断；它不代表已测得的实验误差。
- campaign 运行完成后，评价者用私有测量表标记实际被查询的阈值附近化合物；主结果仍按原 50 次查询计算。另报告每条轨迹中“阈值附近查询数/其中命中数”及“50 次查询中其余精确且远离阈值的命中数”。删失结果不强行归入远离阈值的精确测量集合，单列为不可用于这个诊断。**不重跑、不中途换池、不把诊断性再计分称作新的 50 次完整 campaign。**
- 若未来需要真正移除阈值附近分子并重新搜索，那必须构造带新哈希的新池，重跑相同预算与对照，并重新计算随机期望；不使用当前轨迹冒充该实验。
